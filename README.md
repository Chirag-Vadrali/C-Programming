# C Programming

A structured collection of C programming practice programs, mini-projects, memory-management examples, file-handling exercises, and Data Structures & Algorithms practice.

This repository documents my progression from C fundamentals to pointers, structures, dynamic memory allocation, file I/O, and DSA.

## Compilation

Using GCC:

```bash
gcc filename.c -o program
./program
```

On Windows:

```bash
gcc filename.c -o program.exe
program.exe
```

For programs using the math library, use:

```bash
gcc filename.c -o program -lm
```

## Learning Approach

The programs are organized progressively rather than as a single application. Each file focuses on one or more C concepts so that the language fundamentals can be practiced independently before combining them in larger programs.

The progression is broadly:

```text
C Fundamentals
      ↓
Operators & Conditions
      ↓
Functions
      ↓
Loops
      ↓
Arrays & Strings
      ↓
Structures & Enums
      ↓
Pointers
      ↓
Dynamic Memory
      ↓
File Handling
      ↓
Mini Projects
      ↓
Data Structures & Algorithms
```
