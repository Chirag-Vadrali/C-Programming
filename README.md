# Compilation

The programs can be compiled using **GCC**.

### Linux / macOS

```bash
gcc filename.c -o program
./program
```

### Windows

```bash
gcc filename.c -o program.exe
program.exe
```

For programs requiring the math library:

```bash
gcc filename.c -o program -lm
```

---

# Example
